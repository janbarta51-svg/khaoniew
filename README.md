# Khaoniew Thai Bistro – týdenní menu

Tento veřejný repozitář obsahuje data pro polední menu restaurace Khaoniew Thai Bistro.

## Nedělní aktualizace

1. Otevři [Pages CMS](https://app.pagescms.org/) a přihlas se přes GitHub.
2. Povol přístup k repozitáři `janbarta51-svg/khaoniew`.
3. Otevři **Týdenní menu**.
4. Vyber datum následujícího pondělí.
5. Uprav ceny a jídla od pondělí do pátku.
6. Klikni na **Save**.

Web načítá soubor `weekly-menu.json` automaticky. Anglické názvy a popisy jsou volitelné; prázdné pole se nahradí českým textem.

> Zachovej pět dní v pořadí pondělí až pátek. Každý den může mít libovolný počet hlavních jídel.
